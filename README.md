# myWebOS
A simple WebOS I made for the Stardance challenge. Built with HTML, CSS and JavaScript.

**Live site** https://kratak78.github.io/myWebOS/

## Features:
- draggable windows
- themes (dark and pastel)
- Customizable wallpaper (file upload, drag-and-drop or `Ctrl+V`
- apps
  - Home (welcome window)
  - Notes
  - Cookie Clicker
  - Settings
  - music (you have to upload your own audio files)

## how to use it:
Clone the repo and open `index.html` in a browser, or open the hosted version through the link on top of this README.

## how it works:
- Notes, theme selection, wallpaper background and game progress are automatically saved to `localStorage`
